3.1 Pegawai mengambil masa yang lama untuk mencari pekeliling terkini kerana versi lama masih disimpan dalam folder perkongsian.

3.2 Rules on remote work are spread across more than one document, and staff are not sure which one applies.

3.3 Cloud adoption is limited because the current guideline keeps all official data on-premise.

## 4. Hala Tuju 2025 / Direction for 2025

4.1 Adopt a cloud-first approach for new systems (a new guideline is being prepared).

4.2 Pilot a knowledge search tool so officers can find the latest rules quickly.

4.3 Review human resource SOPs so that remote work rules are consistent.
