# Cloud-First Guideline 2025

Issued by: Office of the State Chief Information Officer (CIO), Kerajaan Negeri Contoh
Reference: GP-ICT 2/2025
Date issued: 15 January 2025
Effective date: 1 February 2025

Note: Kerajaan Negeri Contoh is a fictional government. All names, numbers and dates in this document are invented for demonstration only.

## 1. Purpose

This guideline makes cloud the first choice for new State Government systems, while keeping the most sensitive data on-premise.

## 2. Supersession

This guideline supersedes the Guideline on the Use of Cloud Services 2022 (GP-ICT 1/2022) with effect from 1 February 2025.

## 3. Scope

This guideline applies to all departments, agencies and ICT vendors that store or process State Government data.

## 4. Cloud Use by Data Classification

| Classification | Where it may be stored | Who approves |
|---|---|---|
| Public | Any approved cloud service | Head of Department |
| Internal | Approved in-country cloud regions | State CIO |
| Confidential | Approved in-country cloud regions, encrypted | State CIO |
| Secret | On-premise State Data Centre only | Not allowed in the cloud |

4.1 Internal and Confidential data may be stored in approved in-country cloud regions with the approval of the State CIO.

4.2 Secret data must remain on-premise in the State Data Centre.

## 5. Approval Process

5.1 Departments submit the Cloud Use Application Form to the Office of the State CIO.

5.2 The State CIO decides within 14 working days of receiving a complete application.

5.3 Approved services are listed in the State Approved Cloud Services Register.

## 6. Security Requirements

6.1 Data must be encrypted at rest and in transit.

6.2 Multi-factor authentication is required for all administrator accounts.

6.3 Access logs must be kept for at least 12 months.

## 7. Effective Date

This guideline takes effect on 1 February 2025.
