# Guideline on the Use of Cloud Services 2022

Issued by: Office of the State Chief Information Officer (CIO), Kerajaan Negeri Contoh
Reference: GP-ICT 1/2022
Date issued: 1 March 2022
Effective date: 1 April 2022

Note: Kerajaan Negeri Contoh is a fictional government. All names, numbers and dates in this document are invented for demonstration only.

## 1. Purpose

This guideline sets the rules for using cloud services in departments and agencies of Kerajaan Negeri Contoh.

## 2. Scope

This guideline applies to all departments, agencies and ICT vendors that store or process State Government data.

## 3. Data Classification

Official data is classified into four levels: Public, Internal, Confidential and Secret. The data owner is responsible for classifying the data.

## 4. Where Official Data May Be Stored

4.1 All official data, including Internal, Confidential and Secret data, must be stored on-premise in the State Data Centre.

4.2 Public cloud services may only be used to publish Public information, such as public websites and open data portals.

4.3 Email and collaboration tools must be hosted on-premise.

## 5. Exceptions and Approval

Any exception to section 4 requires written approval from the State CIO. This guideline does not set a time limit for deciding on exception requests.

## 6. Effective Date

This guideline takes effect on 1 April 2022.
